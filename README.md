# 🎙️ Text to Voice · Streamlit

A simple and user-friendly **Text-to-Speech (TTS) web application** built with **Python and Streamlit**. Convert written text into natural-sounding speech directly from your browser and download the generated audio as an MP3 file.

🔗 **Live Demo:** [https://text-too-voice-fzukmgckpcckflrqxgfw4n.streamlit.app/](https://text-too-voice-fzukmgckpcckflrqxgfw4n.streamlit.app/)

---

## ✨ Features

- 📝 Enter any text and convert it to speech
- 🔊 Listen to generated speech directly in the app
- 🌍 Support for multiple languages
- 🎚️ Slow speech option for easier listening
- 💾 Download generated speech as an **MP3**
- 🖥️ Simple and responsive Streamlit interface
- ☁️ Easily deployable on Streamlit Community Cloud

---

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **gTTS (Google Text-to-Speech)**
- **HTML/CSS**
- **Streamlit Community Cloud**

---
🎯 How to Use
Open the application.
Enter your text in the text box.
Select your preferred language.
Choose the speech settings.
Click Convert to Speech.
Listen to the generated audio.
Download the speech as an MP3 file.
